# NNN Tracker

Webapp nhỏ, dùng cá nhân, để theo dõi thử thách 30 ngày tháng 11.

- Điểm danh mỗi ngày (giữ vững / vấp ngã), chuỗi ngày liên tiếp, chuỗi dài nhất
- Lịch 30 ngày, sửa được các ngày đã qua
- Ghi chú + mức độ cám dỗ mỗi ngày
- Nút **SOS**: bài thở 60 giây + gợi ý hành động
- Xuất / nhập dữ liệu JSON để sao lưu
- Sáng / tối, cài được lên màn hình chính điện thoại

Dữ liệu chỉ lưu trong `localStorage` của trình duyệt — không có server, không gửi đi đâu.

Chạy: mở `index.html`, hoặc dùng GitHub Pages (Settings → Pages → Deploy from branch `main`, thư mục `/`).
